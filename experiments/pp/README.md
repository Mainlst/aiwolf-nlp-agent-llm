# Power-play experiments

`fixed_boards_v2/` contains the server-reachable 120-board grammar used by the paper. `fixed_boards/` supplies the shared scorer, judgment rubric, and generator helpers; its older generated corpus is not the paper's accepted dataset. `v2/` supplies the P+/P-PP policies and original normal-game analysis. `revision/` supplies the A/B stage and factorial designs.

Follow the [offline release entry point](../../README.md) for reanalysis. The [artifact index](../../docs/artifact-index.csv) identifies all accepted results. The retained generation code and dated specifications describe historical protocols; new runs need new settings and directories.
